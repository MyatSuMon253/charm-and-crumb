# Frontend Customizer Skill

Use this skill when building the Charm & Crumb frontend-only jewelry customizer.

## Responsibilities

- Keep the app in the Next.js App Router frontend with no backend dependencies.
- Match the warm boutique visual direction: cream backgrounds, serif headings, soft cards, and brown/blush accents.
- Preserve the guided flow: choose base and material, curate charms, drag charms onto the piece, review the order, and confirm cart state.
- Verify changes with lint and production build.
